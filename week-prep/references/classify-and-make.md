# 仕分けて、作り切る（手順2〜4）

## 4つの状態

| 状態 | 付ける時 | ボードに書くこと |
|---|---|---|
| `ready` 準備済み | 当日使う資料・シート・予約が、すでにある（前の週にAI・本人・メンバーが用意した） | もの・使う日・誰がいつ作ったか・場所・当日の一言 |
| `made` AIが作った | 未準備だったものを、今回AIが作った（資料・アジェンダ・台本・文面・表） | 使う場面・中身・状態（そのまま使える／何を埋めれば使える）・パス |
| `you` 本人が動く | 本人にしかできない判断・発言・送信・最終確認 | いつ・所要時間・どうやるか・使うもの・終わりの目安 |
| `ask` 他の人に依頼 | 準備の持ち主が他の人、または重なりの連絡・欠席・代理のお願い | 誰に・手段・送る時・期限・お願いすること・全文 |

- 準備物が要らない予定（朝会、聞くだけの会など）は `ready` にし、「準備物なし」と書く
- 私用の予定（通院・家族の用事など）は状態を付けず、ボードにも載せない。重なりの確認にだけ使う
- 1つの予定に複数の仕事がある時は分ける（例：打ち合わせ自体は `ready`、終わった後のお礼メールは `made`）
- 本人の欄は「判断・発言・送信・最終確認」に絞る。作業をAIや他の人へ寄せられる時は、そちらに回す
- 誰をどの案件に入れるか、といった細かい割り振りは本人の欄に入れず、担当のマネージャーに基準を渡す依頼にする（`my-profile.md` の任せる仕事に従う）

## 本人が動くことの書き方

- `when`：「月 8:00〜8:20」「今夜」「打ち合わせ後」など、動く時刻
- `dur`：所要時間（「15分」）
- `how`：何をどう決めるか・話すか。2つ以上なら①②で並べる
- `use`：使うファイル・文面のID・準備パックの箇所
- `done`：終わったと言える状態（「3つとも決まった」「送信済み」）
- グループは「今夜〜月曜の朝」「月」「火」…の順。月曜の朝に送る依頼はまとめて1件にする

## 先に決めてほしいこと

重なりの優先、出るか出ないか、目的が分からない予定の扱いなど、本人が決めないと準備が進まないものは、準備パックの冒頭に「0. 先に決めてほしいこと」としてAI案つきで並べる。ボードでは「今夜〜月曜の朝」の最初の方に1件にまとめる（例：「①〜③を決める」）。

## 重なりの扱い

- 優先する方を決め（決められなければ「先に決めてほしいこと」へ）、もう一方には連絡文を用意する（欠席・リスケ・代理の進行・別の場で扱う）
- 社外の方へのリスケのお願いは、候補日を3つ添える。候補日は本人の予定の空きから選び、移動時間も見る

## 重点アクションの見込み

来週の重点アクションを1つずつ、`w` 来週の山場（日時）、`r` 詰まりどころ、`s` 見込み（`green`＝いける／`amber`＝一部持ち越し・要注意）で書く。重点アクションのために今できること（資料・依頼文）は、このタイミングで先に作っておく。

## 作り方の型

| 予定の種類 | 作るもの |
|---|---|
| 予定の重なり | 優先しない方への連絡文（社外ならリスケのお願いと候補日3つ） |
| 社外の方とのオンライン会議 | 会議室・フォンブースの予約（許可があれば予約まで。なければ予約リストを「本人が動くこと」に） |
| 定例ミーティング | 前回の宿題の回答・進み具合・決めたいことの資料 |
| 商談・顧客訪問 | 前回の商談の結果（先方が気にしていたこと・こちらの約束）→今回話すこと・聞くこと・提案資料・次の一手 |
| 本人が主催の会議 | アジェンダ（目的・決めること・時間配分・持ってきてもらうもの） |
| 他の人が主催の会議 | 本人が言うこと・決めてほしいこと・判断の軸 |
| 1on1 | 相手の最近の動き、前回の宿題、伝えたい期待 |
| メールを送る必要があるもの | メールの文面（既存のやりとりへの返信なら件名もそのまま） |
| 社外への依頼・お礼 | メールの文面（打ち合わせ後のお礼は、決まったことを【　】で残す） |
| 朝会・全社での話 | 数分の台本（話す順・数字の出典） |

作る時の決まり：

- 事実は出典（メール・チャットの日付、議事録）がある範囲で書く。推測には「要確認」を付ける
- 社外宛ては丁寧な敬語。社内宛ては `my-profile.md` の口調どおり
- **呼びかけは `my-profile.md` の「呼び方と口調」の表どおりにする。** 表にない相手は、本人が送った過去のメッセージでの呼び方に合わせ、分からなければ「◯◯さん」にして最終メッセージで確認する
- 依頼文は1本で1つの用件。複数ある時は①②で並べる
